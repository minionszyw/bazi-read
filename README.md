# bazi · AI Agent 命理分析

## 简介

直接在对话中输入出生资料，完成原局、岁运及分项分析，并继续追问。
本地排盘引擎计算静态资料，分析依据古籍论法指南；完整报告保存为JSON，追问单独解释。

- [技能文档](.agents/skills/SKILL.md)：环境检查与工作流。
- [分析指南](docs/analysis.md)：分析方法、资料复用和保存约定。
- [输出模板](examples/output.template.json)：完整报告骨架。

## 安装

要求Python 3.10+，在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
```

已有环境时先检查依赖，仅在缺少时安装。

## 使用

直接提供姓名（可选）、性别、历法、出生年月日时分、出生地/经度和出生记录时区，例如：

> 我叫小林，男，公历1990年5月17日14:30，出生地北京。请分析原局和今年的岁运。

信息有关键歧义时先补问。未提供姓名时使用“用户1”；不同资料由稳定case_id区分，同名也可分别管理。
首次完整报告默认保存至 `outputs/<case_id>/report-001.json`，并返回文件链接。

随后可直接追问：

> 刚才为什么这样判断事业？
>
> 请看看小林明年的情况。

追问采用自然语言，不写入完整报告。需要更新报告时明确提出：

> 请把小林明年的分析更新到报告，保留旧版。

更新另存递增版本；修正生辰或规则时重新排盘并修订分析，不自动覆盖原文件。
跨会话可提供case_id或已有报告；同名且对象不明确时先确认。

历法依赖sxtwl（BSD-3-Clause），时区数据由tzdata提供，感谢寿星天文历原作者许剑伟及sxtwl维护者。
古籍核验、地点数据许可及解释限制见分析指南；模型和数据处理方式由实际运行环境决定。
