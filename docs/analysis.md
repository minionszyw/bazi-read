# 人工命理分析指南

引擎只提供传统体系中的可重算事实。历法算对不意味着人生预测已经验证。以下为阅读路径，不自动输出结论。

1. 月令与格局：《子平真诠》〈论用神〉，以日干配月令，查看藏干及透干，再区分格局。用神在这里的语境不同于一概“补弱抑强”。输出natal与season可供定位；不能因月支一个字就确定全局。
2. 力量与根气：《滴天髓》及注本、《三命通会》相关篇。结合得令、通根、透藏、党众与生克制化；先检查藏干同类及位置，再看受到何种作用。十二长生不是力量百分数，五行字数不等于旺衰。
3. 成败救应：《子平真诠》〈论用神成败救应〉等。沿格局主线判断何者损伤、何者补救，兼顾日主承受条件。relations仅证明字面组合，合而不化、争合、隔位及刑冲后果必须人工判断。
4. 寒暖燥湿与气势：《穷通宝鉴》按日干与季节条目对读，《滴天髓》讨论全局流通。入节深浅是天文时长；不可把节后第几天直接机械等同某藏干独占司令。各书分日用事说并不一致。
5. 喜忌：先写所采用的“用神”定义，再陈述喜忌成立条件、制约与例外。不得将缺某五行直接解释成必须补某五行。
6. 岁运：先原局后大运再流年及流月。输出的岁运十神以原局日干为参照；组合出现不直接等于发生某件事。大运前后五年如何分看属于解释规则，未交给计算层自动定夺。
7. 六亲、事业、财务、婚恋等：列明参照的十神、宫位与原文条件，区分原局依据和岁运推演，不把神煞单项命中作为吉凶结论。

## 建议记录格式

每条人工判断记录：所用版本及篇章 → 排盘字段 → 论法 → 必要条件 → 反例/救应 → 时间规则敏感性。不同书的论法分开记录，再解释如何取舍。

## 补充阅读与版本

《渊海子平》1634明刊本与《三命通会》1578刊本为主要查考；《子平真诠》1926文明书局本为格局分析主线。《滴天髓》正文、原注和任氏《阐微》须区分；《穷通宝鉴》与徐乐吾评注分开。

太阳时、午夜、23点换日和晚子借干可以影响日主，从而使十神全部变化。比较结果应先检查四柱差异，再讨论解释，不用已知人生经历反向隐瞒规则选择。
