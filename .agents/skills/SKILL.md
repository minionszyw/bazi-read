# AI Agent 命理分析

## 安装依赖

先从本文件所在目录向上两级定位项目根，检查项目环境，仅在缺少依赖时安装。要求Python 3.10+；在项目根运行 `.venv/bin/python -c "import bazi, sxtwl"` 检查，虚拟环境不存在时才创建：

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
```

已有虚拟环境但缺少包时，只执行安装命令。

## 工作流

先读[分析指南](../../docs/analysis.md)，按[输出模板](../../examples/output.template.json)组织报告。以项目根为基准，古籍位于 `../子平古籍/`，完整报告保存到 `outputs/`；需要保存时再创建目录。

1. **识别资料**：直接从对话接收出生资料，按指南第5节处理姓名、资料编号与复用；追问对象不明确时先补问。
2. **解析生辰**：整理birth/rules/options并保留来源，不将name/case_id传给排盘引擎。历法、同名闰月、生时、时区或地点有关键歧义时先补问；已明确的资料不重复确认。
3. **排盘**：用Python `calculate(birth, rules, options)`，或将补齐资料写入任务临时文件后调用 `.venv/bin/bazi chart --input case.json`。地点查询用 `.venv/bin/bazi places 查询词`。核对返回input/rules和warnings，按指南处理边界。
4. **分析原局**：保留真实引擎结果，按日干月令→力量根气→格局成败救应→寒暖燥湿→气势→喜忌分析，关键判断随附依据、论法、来源、条件及未决项。
5. **分析岁运与分项**：首次默认大运概览及当前立春年，按可信时刻计算年份；交运段分别解释，流月、辅助及溯源按需展开。默认分项为性情、学习、事业、财务、婚恋、六亲。
6. **保存报告**：首次完整分析后按指南第5节保存，成功后在对话中告知文件链接。
7. **回答追问**：用自然语言解释当前问题，不向报告追加问答；新年份或资料更正按指南处理。

姓名、编号、文件版本和资料修订的细则见指南第5节。模板是空骨架，不是引擎输入。

## 注意／限制

- 先区分引擎事实与分析解释，不手填干支，不把未执行调用或未成功保存写成已完成。
- 遵守指南中的古籍版本和核验状态；未亲自核验的页码、引文填null，不编造出处。古籍目录不可用时说明无法核验，不假称已读原文。
- 分开说明格局用神、扶抑与调候；五行计数不等于旺衰，关系匹配不等于合化，神煞不单独决定吉凶。
- 用条件性论法表达结论，不输出精确概率或必然事件，不倒改规则迎合现实经历。
- 不用模板空值排盘，不猜缺失生时；无旧上下文或报告时不假装记得旧分析。资料更正与报告更新遵循指南，不自动覆盖文件。
