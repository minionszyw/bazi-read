# AI Agent 命理分析

## 安装依赖

从本文件所在目录向上两级定位项目根，以下命令在项目根执行。要求Python 3.10+。
先检查 `.venv/bin/python -c "import bazi, sxtwl"`；环境或依赖缺失时安装，已有环境不反复创建：

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
```

## 工作流

先读[分析指南](../../docs/analysis.md)，按[唯一输出模板](../../examples/output.template.json)组织结果。模板是空骨架，不是引擎输入。

1. **解析资料**：从用户原文整理birth/rules/options，保留来源。历法、同名闰月、生时、时区或地点有关键歧义时先补问；已明确的资料不重复确认。
2. **排盘**：用Python `calculate(birth, rules, options)`，或将已补齐资料写入任务临时文件后调用 `.venv/bin/bazi chart --input case.json`。地点查询用 `.venv/bin/bazi places 查询词`。检查返回input/rules和warnings，按指南处理边界与错误。
3. **呈现排盘**：chart保留真实schema2.0结果。首次默认大运概览及当前立春年，年份按执行时可信时刻计算，不从模板推断；流月、辅助及溯源按需展开。
4. **原局分析**：日干月令→力量根气→格局成败救应→寒暖燥湿→气势→喜忌。每条关键判断随附依据、论法、来源、条件及未决项。
5. **岁运分析**：先原局后大运流年；合并读取原局和新增关系，交运段分别解释，必要时再展开流月。
6. **分项解析**：默认性情、学习、事业、财务、婚恋、六亲；不足就保留未定，不套通用吉凶描述。
7. **持续问答**：解释旧结论可复用结果，新年份按需重排；修正生辰或规则时增加birth_revision并重建受影响结论。

输出一个JSON对象，不附Markdown围栏或JSON外说明。首报填写input/chart/natal/fortune/domains；澄清只填相关资料和questions，追问填followup及需要更新的部分，其余为null或空数组。字段和来源格式见指南第5节，不使用全局判断编号或独立Schema。

## 注意／限制

- 引擎事实与agent解释分开，不手填干支，不把未执行调用写成已完成。
- 遵守指南中的古籍版本和核验状态；未亲自核验的页码、引文填null，不编造出处。
- 格局用神、扶抑取用和调候所需分开说明；五行计数不等于旺衰，关系匹配不等于合化，神煞不单独决定吉凶。
- 结论为传统论法的条件性解释，不输出精确概率或必然事件；现实经历只作用户背景，不倒改规则迎合经历。
- 模板中的空值不是有效生辰；当前引擎不支持缺时或模糊时间。无旧上下文时不假装记得旧分析；未要求长期保存时仅维护会话状态。
